# ทีมสงครามแห่งการยึดครอง

เว็บรวมทีมยอดนิยมโหมดสงครามแห่งการยึดครอง (Summoners War) พร้อมทีมตีที่ชนะจริงและรูนที่ใช้

- เว็บ: https://siege.thaimapgame.com
- ฟอร์มส่งข้อมูล: https://docs.google.com/forms/d/e/1FAIpQLSc1rqq_RnKAq3Cj2cuzaY803iS1UplVPSjjcH0cPlXlvbo0Ig/viewform

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | หน้าเว็บ |
| `data/monsters.json` | ชื่อมอน ธาตุ และไฟล์ไอคอน (`unkN` = มอนที่ยังไม่รู้ชื่อ แสดงเป็น "?") |
| `data/ranked.json` | อันดับทีมตั้งรับ (`def`) และทีมโจมตี (`atk`) จาก SWLens |
| `data/matchups.json` | ทีมตีที่ชนะทีมตั้งรับ พร้อมวันที่และภาพรูน |
| `img/mon/` | ไอคอนมอน |
| `img/runes/` | ภาพรูนที่ตัดแล้ว (ไม่มีชื่อผู้เล่น) |
| `tools/` | สคริปต์ตัดรูปและเพิ่มข้อมูล |

## เพิ่มข้อมูลใหม่

1. ดูรายละเอียดวิธีใช้ใน `tools/add_matchup.py`
2. เปิดดูภาพที่ตัดใน `img/runes/` ทุกครั้ง ต้องไม่มีชื่อผู้เล่นหรือรูปโปรไฟล์
3. ทดสอบในเครื่อง: `python -m http.server` แล้วเปิด http://localhost:8000
4. commit แล้ว push ขึ้น `main` เว็บจะอัปเดตเองภายใน 1–2 นาที

ทีมใดถ้าไม่มีภาพรูนครบ 3 ตัว จะไม่ขึ้นเว็บ

## ลิงก์เฉพาะทีม

`#atk-r1` = ทีมโจมตีอันดับ 1, `#def-r5` = ทีมตั้งรับอันดับ 5, `#atk-x-m2` = ทีมกิลด์ที่มาจากข้อมูล m2
